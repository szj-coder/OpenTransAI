# 图片翻译实施计划

依据 `docs/image-translation-interaction-spec.md`，实现修订后的 A01—A28；用户后续要求图片入口改为原生右键，取消悬停方案。基线 cef5316；分支 codex/image-translation。保持 MV3、Chrome 123、原生 JS 和现有版本；不新增运行依赖。

## Task 1: 视觉协议和可指定目标语言的翻译

在 core.js / stream.js 中实现 recognizeImage(image, settings, options)，image 为 {dataUrl,width,height}；返回 {text,sourceLanguage,warnings}。translate 的 options 增加 targetLanguage、sourceLanguage，省略时保留旧自动方向。OCR 非流式完整校验，翻译支持流式。有效进展 60 秒超时；错误提供安全的 code。三种协议、无文字、多语言、模糊提示、输入限制、取消和旧规则回归均测试。

## Task 2: 标签页任务与 Chrome 边界

后台统一按 tab 协调，顶层拥有浮窗；任务标识覆盖读取、识别、翻译、取消、重试与配置版本。图片按实际内容摘要复用，保持内存边界。提供图片原生菜单、截图入口、可选全站授权、后台读取与本地截图裁剪；凭据不发往页面。

## Task 3: 统一浮窗和图片入口

内容脚本拆分 UI、入口和截图模块。移除图片悬停按钮、鼠标移动/DOM 监听和计时器，保留划词按钮与原生图片右键入口。落实唯一浮窗、原文折叠、单滚动区、取消、重译、复制已有内容、目标语言、展开、跟随控制和焦点恢复。框选确认才替换任务；取消恢复旧任务。

## Task 4: 集成验收和交付

Node 与浏览器测试映射 A01—A28；验证原生边界或记录准确阻塞。运行 test、check、package、diff --check，核对产物。更新 README 和验证记录。未请求提交、推送或发布。

## 决策

- 图片复用当前视觉模型先 OCR 后翻译；划词保留自动方向。
- 图片载荷最多 4MiB、单边 8000px、文本 12000 字符；超限提示框选，不截断。
- 原有 enabled 为总开关；目标语言只改变当前任务。
- 首版内存只保留当前任务和它已确认的内容；不建立历史。
- 网页截图可选申请全站权限；临时 activeTab 入口仍可用。

## 2026-09-18 交互调整

按用户最新要求，点击浮窗外部的网页区域自动关闭并取消请求；内部操作与框选截图排除。iframe 外部点击由后台转交顶层，迟到点击不能关闭新浮窗。外部关闭不恢复旧焦点，显式关闭和 Esc 保留焦点恢复。

## 2026-09-18 图片内容排版

识别与翻译提示保留原图标题、段落、列表、代码和可靠表格；保持既有 JSON 字段，以受限标记传递结构。图片/截图原文和译文采用安全 DOM 排版，复制导出可读文字/TSV；不可靠表格原样逐行回退，划词维持纯文本。验证三协议请求、流式节点及选区稳定性、复制、同语言结果和窄屏布局，无新依赖或版本变动。
