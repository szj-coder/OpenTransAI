## 协议、任务与权限补充

- OpenAI 兼容（含 custom）、Anthropic、Gemini 分别验证原端点、认证、图片内容块及安全识别提示。识别只接收完整 `{text, sourceLanguage, warnings}`；混合语言、BCP47 扩展、空结果、模糊/表格警告有验证。
- SSE 心跳、推理片段、纯空白不能延长业务空闲超时；有效正文增量可延长。端口关闭和总开关取消活跃请求；按标签页替换任务，iframe 和顶层不能并行覆盖。
- 配置版本为不含 Key 的随机版本；旧版本识别复用请求被拒绝，公开状态和页面消息不携带凭据。
- 截图前后校验原 document/nonce/viewport；额外记录切页和缩放事件，A→B→A 不能绕过校验。框选期间所有 frame 隐藏入口，新 frame 的划词入口 claim 也被抑制。
- API 权限撤销、图片域授权拒绝、授权 token 单次使用及绑定 document、受限来源、空选区、非法选区、截图权限失败均有测试。
- 保留划词自动方向、密码框排除、文本输入选区、纯文本渲染与 Key 隔离；既有协议切换保留地址/模型/Key/语言/思考偏好的浏览器回归已迁入统一验收页。
- 只读审查发现并关闭 3 项问题：中途切页截图竞态、关闭后截图授权迟到重开、空识别切换语言重复 OCR；修复均有回归。后台与 UI 复核范围内无未解决 P1。

## 右键入口与通用性

- 生产图片入口只记录显式 `contextmenu` 的图片元素；原生菜单回调提供权威 `srcUrl` 和 `frameId`。记录本身不读取像素、计算样式或发后台请求，也不阻止网页原生菜单。
- 显式选择后优先读取当前选定图片；元素已复用、移除或无法定位时，使用浏览器选中的 URL 并按已有权限规则回退。不会扫描其他图片寻找匹配节点。
- 浏览器回归覆盖小图、普通 `img`、透明图片、`picture/srcset`、动态新增和延迟加载图片、链接图片、跨域和 iframe；单元测试补充开放 Shadow DOM 的事件路径。无 X/Twitter 域名或专用节点分支。
- 右键菜单被网页拦截，或 CSS 背景、画布没有浏览器图片菜单时，使用扩展图标右键菜单“框选截图翻译”。不承诺任意网页内容都具有原生图片菜单。
- 划词按钮继续使用原 26px 图标，跨 frame 通过 `ENTRY_CLAIM` 协调，截图期间抑制入口。
- 原悬停方案曾复现整页观察器自循环，之后已修复；当前进一步删除整套图片悬停检测，不再保留该观察器路径。此前悬停时序和双层背景匹配记录不再作为当前验收条件。

## 未验证层级及人工步骤

浏览器安全策略拒绝访问 `chrome://extensions`，不能通过现有浏览器工具重新加载原生扩展。未尝试绕过该限制。本轮下列项目不能标为通过：

1. 在原生 Chrome 手动重新加载扩展并刷新页面，确认图片原生右键菜单及截图右键菜单的 activeTab 入口。
2. 全站及图片域授权的允许、拒绝、撤销；拒绝后旧任务保持，右键菜单临时授权仍可截图。
3. 原生 `captureVisibleTab` 在实际 DPI、滚动条、页面缩放、切页/返回、受限页面下的裁剪边界。模拟测试覆盖计算和时序，但不能代替浏览器原生截图返回值。
4. 使用用户自行配置且支持视觉的模型，分别验证三协议实际识别/翻译；包含混合语言、表格、模糊图片、无文字及服务限制。文本“测试连接”不代表视觉验证。
5. 授权窗口长时间停留导致 MV3 worker 被系统回收时，请关闭过期授权窗口，从原页面重新发起。授权请求仅在内存中保存，不持久化截图、识别结果或待授权来源。

截图权限依据：[Chrome tabs.captureVisibleTab](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)。页面不能代替用户授予权限，须通过扩展自有界面按钮触发请求。
