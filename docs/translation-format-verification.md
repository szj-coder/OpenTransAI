## 本次修改

- `extension/lib/core.js`：源/目标语言先规范化大小写、下划线和标准别名，再计算自动方向和校验。输出的目标代码仍使用设置或显式请求值，流式预览和最终结果共用同一规则。
- 中文目标只接受明确匹配脚本的代码：`zh-Hans`、`zh-CN`、`zh-SG` 对应简体；`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 对应繁体。显式脚本优先于地区。裸 `zh`、相反脚本和其他语言仍拒绝。其他未限定地区的目标允许同语言、同脚本的地区代码；不会丢弃变体或私有扩展后宽松放行。
- 已知源语言仍要求规范化后的代码一致。未更改图片识别、图片第二步正文输出、自动方向规则、请求次数、协议、模型或配置。
- `extension/lib/diagnostics.js`：增加 `languageField`、`expectedLanguage`、`actualLanguage` 白名单。仅保存基本语言/脚本/地区代码，不保存私有扩展、自由文本、原文、译文或 Key。诊断页现有字段展示与复制功能直接显示新字段，旧日志不回填。
