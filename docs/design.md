# OpenTransAI 设计

无构建依赖的 Chrome Manifest V3 扩展，原生 HTML / CSS / JavaScript。

- 点击浏览器插件图标直接显示 `popup.html` 配置窗口。宽 400px、最高 600px，保留原设置设计的色彩、字体和 8px 输入框圆角；压缩字段间距以容纳五字段、开关、测试连接及保存。没有独立 options 页面或跳转入口。
- 五字段依次为协议类型、API 地址、模型、API Key、默认语言。保存当前服务，切换协议保留本窗口的草稿，关闭窗口不保存草稿；保存成功后立即关闭窗口，失败保持打开。连接测试使用当前表单，不自动持久化。旧版本设置可继续读取。
- 模型标签旁增加思考模式开关，默认 false，旧配置没有该字段时按关闭处理。只对 DeepSeek 官方 origin 的 OpenAI 兼容请求添加 `thinking.type: enabled / disabled`；其他协议或域名不添加参数，配置界面禁用开关并说明适用范围。
- 后台仅发送 waiting / thinking / translating 三种阶段值，不发送原始思考文本。waiting 在请求发出时触发，thinking 由真实 `reasoning_content` 分片触发，translating 由正文分片触发；阶段去重且不回退。前端显示简短说明与请求已用时，首段译文到达、失败或关闭后停止计时并收起说明。
- 只有点击划词图标才发送文本。默认语言不同则译为默认语言；相同（包括地域变体及简繁中文）则译为英语。一次模型请求完成语言识别和翻译。
- OpenAI 兼容和 Anthropic 使用 `stream: true`，Gemini 使用 `streamGenerateContent?alt=sse`。SSE 解析处理跨网络块、UTF-8 和换行边界；增量解析 JSON 的语言字段与 translation 字符串，解码转义后才显示。完整响应仍进行方向、格式和长度校验。
- 通过 `runtime.connect` 将片段从后台发送到内容脚本。端口只接受一次翻译，不接受配置读写。旧版内容脚本的一次性消息在后台入口直接提示刷新，不再静默进入非流式路径。断开时取消包括存储 / 权限等待在内的完整请求生命周期；每个页面的新请求取消旧请求。流内错误、截断、缺失结束标记均作为失败处理。首段 / 数据空闲超时 25 秒，单次总上限 180 秒；生成期间每 20 秒端口通信保持 MV3 工作线程活跃。
- 翻译弹框保留用户 `selection-translation-design.html` 的 10px 圆角、边框和柔和阴影；按后续要求调整为默认宽 440px、窄屏收窄，高度随内容增长、上限为 visual viewport 的 70%。原文默认折叠，显示含空格与换行的 Unicode 字符数，点击展开。工具栏、配置页、翻译框和划词按钮统一使用用户提供的 `ai-translate-light.svg` 浅色图标；划词按钮保持 26px，底色、边框和悬停效果配套调整。原暗色 SVG 及 PNG 保留在原路径。目标语言用标签显示自动规则结果，没有增加参考样例的手动目标语言选择功能。
- 外层内容区不滚动；原文和译文使用独立、隐藏滚动条且可键盘聚焦的滚动区。原文最高 144px，同时不超过扣除固定栏后阅读空间的 40%，为矮窗口中的译文保留空间。语言栏、原文折叠栏和底部重译 / 复制固定。错误与复制提示放在译文区域内。
- 浮窗默认靠选区下方，下方不足则上翻并限制在可视视口的 8px 安全边距内。尺寸变化、原文展开、流式追加和 visual viewport 变化后重新测量位置，保留读者的原文和译文滚动位置。
- 正文在稳定的 DOM 中追加片段，以 180ms 透明度淡入显示；不额外做逐字延迟，不反复重建整块正文。减少动态效果模式直接显示。生成完成前禁用复制；失败时保留片段并标记未完成。只在用户接近底部时跟随滚动。
- 关闭、点击外部、ESC 或新选区会取消请求；旧端口消息不能恢复已关闭的面板。浮层处于 Shadow DOM 和 top layer，定位避开视口边缘及浏览器滚动条，原文和译文均按纯文本渲染。
- Key 仅保存在 `chrome.storage.local`，限制 TRUSTED_CONTEXTS；只有配置 popup 能读写。内容脚本不能提供自定义 AI 地址或 Key。AI 域名按需授权，仅 HTTPS 或本机 HTTP，不跟随重定向；无同步、历史、遥测或中转。

验收覆盖 Node 协议 / 生命周期测试、实际本地 HTTP SSE 首段与取消、浏览器内容脚本和悬浮配置交互、尺寸与截图、清单和打包检查。浏览器预览有明确模拟标识，仅用测试 Key；另用用户授权的 DeepSeek 配置测试真实阶段事件，未操作用户 Chrome 原生安装或重新加载。
